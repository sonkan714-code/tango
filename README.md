# 日本語単語カード N3〜N2（韓国語話者向け）

スマホで使える単語カードのウェブサイトです。サーバー不要で、GitHub Pages などに置くだけで動きます。

- 最初は **60語**（イラスト・音声つき）
- **2週間ごとに20語ずつ自動で追加**（全12回・240語、2026年12月8日〜2027年5月11日）
- 覚えた記録は各自の端末（ブラウザ）に保存されます
- ホーム画面に追加するとアプリのように使え、一度開けばオフラインでも動きます

## フォルダの中身

| ファイル | 内容 |
|---|---|
| `index.html` | 本体 |
| `words.js` | 単語データ（`BASE`＝最初の60語、`EXTRA`＝追加分） |
| `img/` | 最初の60語のイラスト（いらすとや） |
| `audio/` | 最初の60語の音声（`w番号`＝単語、`x番号`＝例文） |
| `sw.js` / `manifest.json` / `icon.svg` | オフライン対応・ホーム画面用 |

## くらしの単語（名詞だけ・日常生活）

レベル別とは別に、野菜・果物・食材・台所・家・洗面所・服・文房具・体・町・乗り物・動物の12テーマ、181語を `daily.js` に入れています。最初から全部使えます。カードの表には絵文字（ない単語は韓国語）が出ます。

## 自動追加のしくみ

`index.html` の先頭あたりにある次の2行で決まります。

```js
const START = '2026-11-24', EVERY = 14;
```

`START` の日から `EVERY` 日たつごとに、`words.js` の `EXTRA` のうち `"b":1`、`"b":2`… の単語が順に表示されるようになります。サーバーは何もしていないので、ファイルを置いたまま放っておけば勝手に増えます。

追加分の単語にはイラストと音声ファイルがないので、表は「穴埋め問題」になり、読み上げは端末の音声で行います。

### 日付を変えて確認する

URL の最後に `?date=2027-01-06` のように付けると、その日に開いたときの表示を確認できます。

### 単語をさらに足すとき（半年後など）

`words.js` の `EXTRA` の最後に、同じ形で `"b":13` の単語を足すだけです。`"n"` は他と重ならない番号にしてください。

```js
{"b":13,"k":"漢字","y":"よみ","lv":"N2","pos":"名詞","th":"家・生活","ko":"한국어","masu":"","ex":[["例文。","예문.","例文で色をつける部分"],["例文2。","예문2.","色をつける部分"]],"pt":"ポイント","n":301}
```

- `pos` は `名詞` / `動詞` / `い形容詞` / `な形容詞`
- `th` は `自然・災害` `家・生活` `町・社会` `体・健康` `料理` `動作` `気持ち` `性格・様子` のどれか
- 例文の3つ目は、例文の中に**そのまま含まれる**文字列（活用した形）にする

## GitHub Pages で公開する手順

1. GitHub にログインし、右上の「+」→「New repository」。名前（例：`tango`）を入れて **Public** で作成
2. 作ったリポジトリのページで「uploading an existing file」をクリックし、このフォルダの中身（`index.html`・`words.js`・`img`・`audio` など全部）をドラッグして「Commit changes」
   - `.nojekyll` は隠しファイルなので、ドラッグで入らなくても動作に問題はありません
3. リポジトリの「Settings」→ 左の「Pages」→「Branch」を `main`・`/ (root)` にして「Save」
4. 1〜2分待つと `https://（ユーザー名）.github.io/tango/` で公開されます

ターミナルを使う場合：

```bash
cd tango-site
git init && git add . && git commit -m "単語カードを公開"
git branch -M main
git remote add origin https://github.com/（ユーザー名）/tango.git
git push -u origin main
```
